# LARGO GitHub Pages preview

[Open the website](https://edgarlargo.github.io/edgar-largo-preview/)

This is a static public snapshot for the repository path `/edgar-largo-preview/`. All ten routes are ordinary directories with index.html; no PHP, Node function, database or build is required for hosting. Run `node local-server.mjs` for a local view at http://127.0.0.1:8189/edgar-largo-preview/.

The footer contact form sends inquiries to Edgar Largo Studio through the explicitly configured HTTPS endpoint on edgarlargo.com. WordPress sends the email through its existing SMTP setup; passwords and cookies are never included in this repository or browser requests. Other forms remain preview-only. CMS/admin features and sessions are excluded. Old index.php query addresses are replaced by clean paths; those old PHP addresses are not supported on GitHub Pages. Re-export if the repository name or base path changes.

GitHub Pages publishes the repository root from `main`. Changes pushed to that branch update the preview. `.nojekyll` preserves the exported static files without a Jekyll build. `deployment/pages.yml.example` is an optional, inactive workflow example.

Project cover/depth textures load near the viewport. VR prepares before reaching the viewport and renders when visible. Unused landscape, astronaut and Matrix scene code and 24 exclusive resources have been removed while retaining the introductory stars, photo portrait and active animations. The export contains optimized, versioned Caviar videos and no editor bootstrap or private PHP runtime.

The custom `404.html` page displays a rotating procedural 3D Roadster with `404` number plates and links to Roadster Flight and the homepage. Drag, keyboard arrows and a pause button control the rotation; reduced motion starts with a still view. Geometry, scripts, the fallback photograph and the Three.js license are local assets. Missing nested paths use the same page and retain HTTP 404.

This repository contains the public viewing export only. The complete PHP website, administration and private configuration are maintained separately. The design, fonts, media and models retain their respective rights; public visibility does not grant a blanket open-source license. Bundled library copyright and license notices are retained.

The October 24 loading profile preloads Aeonik Regular, keeps DOM-required font faces ready before text measurement and defers unrelated faces. Mono family names share one font URL. Versioned script/style URLs use final content hashes; home, About and the project archive share their native script URL, while project pages retain their distinct imported bundle. Responsive WebP Q90 images retain the full-size originals in srcset; three lossless 3D texture copies preserve decoded pixels and alpha. The VR bridge batches layout work and skips unchanged writes; early VR preparation, existing scroll timing, typography, graffiti and 404 behavior remain. Reduced-motion hero rendering updates on interaction or state changes. Four unused duplicate BUF files are excluded only from public previews (6,500,674 bytes); local originals remain. These changes are recorded in portable opt-in profiles and replayed by the generator and ordinary WebSync updates. No browser, Lighthouse or tests were run; no measured LCP, INP or FPS improvement is claimed.

The seven published projects now have individual background, text and accent palettes drawn from their own work: warm stone/wood for Vintage Stories, deep teal for Flow, light violet/brand purple for the studio, black/rose for Dixieme, navy/cyan for Spine Surgeons, warm black/gold for Caviar and crimson/white for Euro Energo. The palette also controls project buttons and next-project transitions. Pre-JS colours remain readable and retire when the native router takes over. The collection explicitly enables the source-style image entrance: photos remain visible DOM images with responsive currentSrc, prepare 1000px before view and reveal with the original visual timing. The optional effect never hands HTML visibility to the canvas. Captions, complex content and video retain their content runtime; reduced motion avoids the entrance effect. The decorative fern, its model request and shadow render passes are removed from both native bundles via a portable client profile, also preserved by ordinary WebSync updates. Project texts, order, videos and source imagery remain intact. These are implementation and file-integrity checks; no tests or browser visual runs were performed.

The About process/expertise spray line now follows five smooth cubic Bezier segments with continuous tangents. It enters from outside the left edge and exits beyond the right edge, with endpoint clearance based on the actual brush width. Its purple spray texture, native responsive thickness, scroll timing and reduced-motion state are retained in the portable About profile.

The four expertise cards now show original black vector graffiti letters B, D, M and V in both corners, with the lower corner using the existing 180-degree card header rotation. The mini navigation uses the same B/D/M/V sequence. The SVGs are small editable client images; service content, card backs, native scripts and flip animations remain intact.
